# 같이합서 PWA 데모

제주 뚜벅이 여행자를 위한 즉석 동행 매칭 & 로컬 상생 결제 플랫폼 데모입니다.

## 데모 흐름

- 제주공항에서 성산일출봉까지 동행 찾기
- AI 찰나 매칭
- 매칭 수락 및 픽업 포인트 확인
- 자동 N빵 정산
- 탐나는전 로컬 캐시백 안내

## 실행 방법

정적 PWA이므로 간단한 로컬 서버에서 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:4173/index.html
```

## 배포

GitHub Pages에서 `main` 브랜치의 root 폴더를 선택하면 바로 배포할 수 있습니다.
